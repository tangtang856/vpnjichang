Linux 终端与 VPS 服务器科学上网配置全指南

作者: vpnjichang.wiki 客户端技术组 审核状态: 已验证通过
本篇核心要点

在 Linux 服务器上执行 git clone、拉取 Docker 镜像或调用 OpenAI API 经常遭遇超时。本文详解轻量高效的 Linux 代理配置。

一、下载预编译二进制文件

访问 Mihomo (Clash Meta) 官方开源仓库，根据服务器架构下载对应的 tar.gz 压缩包（如 mihomo-linux-amd64.tar.gz）。解压后将二进制文件重命名为 mihomo 并移动至 /usr/local/bin/，赋予可执行权限：chmod +x /usr/local/bin/mihomo。

二、下载订阅配置并配置 Systemd 守护进程

在 /etc/mihomo/ 目录下创建 config.yaml，使用 curl 直接拉取机场的订阅配置文件：
curl -L -o /etc/mihomo/config.yaml “您的机场订阅链接”
编写 systemd 服务文件 /etc/systemd/system/mihomo.service 实现开机自启与崩溃自动拉起。

三、配置环境变量与终端一键代理脚本

在 ~/.bashrc 中添加快捷别名函数：
alias setproxy=“export http_proxy=http://127.0.0.1:7890 https_proxy=http://127.0.0.1:7890”
alias unsetproxy=“unset http_proxy https_proxy”
在需要代理的终端窗口输入 setproxy，即可让 curl 和 git 畅通无阻。

💡 常见问题与排错答疑 (FAQ)

问：如何验证 Linux 终端代理是否已生效？

答：在终端执行 `curl -i https://ipinfo.io`，查看返回的 IP 是否已经变为机场节点的海外落地 IP。
