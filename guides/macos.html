macOS 苹果电脑客户端配置与节点导入全流程教程

作者: vpnjichang.wiki 客户端技术组 审核状态: 已验证通过
本篇核心要点

针对 macOS 系统的精致 UI 与专业开发环境需求，详解如何通过 Clash Verge Rev 开启系统级网络代理与配置 TUN 模式。

一、macOS 客户端版本选择与芯片适配

macOS 用户主力推荐 Clash Verge Rev，不仅开源免费且完美原生适配 Apple Silicon (ARM64) 与 Intel (x64) 芯片。前往 Release 页面，M1/M2/M3/M4 系列芯片电脑请下载文件名带有 _aarch64.dmg 的版本，Intel 处理器下载 _x64.dmg。

二、安装与解除“应用已损坏”安全提示

打开 dmg 文件将图标拖入 Applications 文件夹。若首次打开提示“已损坏，无法打开”，是因为 macOS Gatekeeper 对未签名开源软件的安全机制。打开终端（Terminal）粘贴以下命令并回车输入密码即可解决：
sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app

三、订阅导入与 TUN 模式深度配置

在 Profiles 界面粘贴订阅链接下载并激活。在设置中开启“系统代理”。对于开发者而言，Terminal 终端命令行（如 brew、git clone、npm install）默认不走系统代理，此时在 Clash Verge 设置中安装 Service Mode 并开启 TUN 模式，即可实现整机所有终端进程全自动高速加速。

💡 常见问题与排错答疑 (FAQ)

问：如何在 Mac 菜单栏快速切换节点？

答：Clash Verge 会常驻在 macOS 右上角状态栏，点击图标即可在下拉菜单中快速切换节点或分流模式。
