macOS 苹果电脑客户端配置与节点导入全流程教程

最后更新: 2026-03-15 阅读时长: 约 8 分钟 适用系统: MACOS
核心指导摘要

针对 macOS 系统的精致 UI 与开发环境需求，详解如何通过 Clash Verge Rev 开启系统级网络代理与配置 zsh 终端代理环境。

一、macOS 优质客户端推荐

  • Clash Verge Rev for Mac（主力推荐）：完美原生适配 Apple Silicon (ARM64) 架构，开销极小，全面接管网络，配合暗色模式体验卓越。
  • Surge for Mac：Mac 平台顶级的专业网络调试与分流利器，功能强大但售价较高，适合对网络有极致追求的专业开发者。

二、Clash Verge Rev 安装与权限授予

  1. 下载 .dmg 镜像文件（注意 M 系列芯片选择 aarch64.dmg，旧款 Intel 选择 x64.dmg）。
  2. 打开 dmg 文件，将 Clash Verge 图标拖拽到 Applications（应用程序） 文件夹中。
  3. 首次在“系统设置 -> 隐私与安全性”中允许该软件运行。如果提示已损坏，打开终端执行：
    sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app

三、订阅导入与 TUN 模式开启

与 Windows 类似，在 Profiles 粘贴机场订阅链接下载即可。但在 macOS 下有一项极重要的功能：

开启 TUN 虚拟网卡接管：在设置中点击安装 Service Mode（服务模式），看到旁边显示小绿点后，开启 TUN 模式。此时包括 Mac 终端 curl、git clone、Docker 镜像拉取以及海外游戏均可全自动享受高速加速，彻底告别在终端手动配置 export http_proxy 的烦恼。
