Clash DNS 深度解析与 Fake-IP 最佳实践指南

作者: vpnjichang.wiki 客户端技术组 审核状态: 已验证通过
本篇核心要点

DNS 解析延迟直接决定了打开网页的第一反应速度。Fake-IP 机制通过巧妙的虚假 IP 映射，实现了毫秒级秒开海外网站。

一、什么是 Fake-IP？它是如何工作的？

传统 Redir-Host 模式下，浏览器访问 google.com 时，电脑必须先等待本地代理内核向远程 DNS 查询并返回真实 IP；而在 Fake-IP 模式下，内核在收到查询请求的 0.1 毫秒内，立即返回一个保留的虚假 IP（如 198.18.0.23），并建立域名映射表。浏览器无需等待直接建立连接，由代理服务器在远端执行真实解析，极大缩短了首包等待时间。

二、Fake-IP 模式的最佳防污染配置范例

在配置文件的 dns 块中，设置 enhanced-mode: fake-ip，配置国内优质 DNS（如 223.5.5.5、119.29.29.29）处理境内域名，配置海外纯净 DoH（如 https://cloudflare-dns.com/dns-query）作为后备 fallback，彻底告别电信联通的运营商 DNS 劫持。

💡 常见问题与排错答疑 (FAQ)

问：Fake-IP 模式下在命令提示符 ping 域名返回 198.18.x.x 是正常的吗？

答：完全正常！这正是 Fake-IP 的标准行为，数据包发送给 198.18 网段后会被客户端内核自动拦截并转发至远程落地节点。
