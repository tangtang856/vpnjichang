基础概念：防火长城 (GFW) 的工作机制与流量阻断原理

分类: 核心网络术语 审核: vpnjichang.wiki 词条小组
概念定义速查

从计算机网络工程角度客观解析防火长城的工作机制，了解审查系统如何识别与处理跨境网络数据包。

一、防火长城的核心拦截手段

防火长城（Great Firewall，简称 GFW）经过二十余年的技术迭代，构筑了多层联动的过滤体系：

  1. DNS 污染（域名投毒）：当境内客户端向本地 DNS 服务器查询受限网站（如 google.com）时，GFW 的旁路监控设备会先于境外真实服务器抢先返回一个虚假的、不存在的 IP 地址，导致用户无法建立连接。
  2. IP 黑名单丢弃：对于已确认提供代理服务或政治敏感的海外服务器 IP，直接在国际出口路由器的路由表（BGP）中下发黑洞路由，发往该 IP 的所有数据包直接静默丢弃。
  3. TCP RST 异常重置：监控到明文 HTTP 通信中包含敏感关键字时，向通信双方伪造发送带有 RST 标志的 TCP 数据包，强制中断当前的连接会话。
  4. SNI 审查与阻断：在 TLS 加密握手的 Client Hello 阶段，客户端发送的服务器域名（SNI）通常是明文的。GFW 会据此域名决定是否在握手瞬间掐断连接。
  5. 主动探测 (Active Probing)：当系统怀疑某台境外 IP 在运行 Shadowsocks 代理时，GFW 会主动从境内发起特定特征的嗅探连接，若境外服务器正常回应验证，该端口会被立即封锁。
