基础概念：防火长城 (GFW) 的工作机制与流量阻断原理

分类: 核心网络术语 审核: vpnjichang.wiki 词条小组
概念定义速查

从计算机网络工程角度客观解析防火长城的工作机制，了解审查系统如何识别与处理跨境网络数据包。

一、防火长城的核心拦截手段

防火长城（Great Firewall，简称 GFW）经过二十余年的技术迭代，构筑了多层联动的过滤体系：

  1. DNS 污染（域名投毒）：当境内客户端向本地 DNS 服务器查询受限网站（如 google.com）时，GFW 的旁路审查设备会抢先伪造一个错误的虚假 IP 地址并返回给客户端，导致访问失败。
  2. IP 黑名单丢弃：直接将已知的违规海外服务器 IP 注入核心路由器的黑名单路由表中，向这些 IP 发送的所有数据包都会在骨干网被直接丢弃（Null Route）。
  3. TCP RST 异常重置：当监控到明文 HTTP 通信或未加密流量中包含敏感关键词时，防火墙会伪造两端的 TCP RST（Reset）包强行切断连接。
  4. SNI 明文探测与阻断：在 TLS 握手时，传统的 Client Hello 会携带明文的目标域名（Server Name Indication）。审查系统通过读取 SNI 即可精确阻断特定网站的 HTTPS 握手。
  5. 机器学习主动探测：当发现某个未知境外 IP 在运行 Shadowsocks 代理时，GFW 会主动从境内发起特定特征的嗅探连接，若境外服务器正常回应验证，该端口会被立即封锁。
